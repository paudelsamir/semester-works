# Syllabus — B.Sc. CSIT Semester VII (Tribhuvan University)

## 1. Advanced Java Programming (CSC409)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60+20+20

### Units

| Unit | Title | Hours |
|------|-------|-------|
| 1 | Programming in Java — Architecture, OOP, Exceptions, Concurrency, File I/O | 8 |
| 2 | User Interface Components with Swing — AWT vs Swing, Layouts, GUI Controls, Menus, Dialogs | 10 |
| 3 | Event Handling — Listener Interfaces, Action/Key/Mouse/Window/Item Events | 4 |
| 4 | Database Connectivity — JDBC Architecture, DDL/DML, Prepared Statements, Transactions | 4 |
| 5 | Network Programming — TCP/UDP Sockets, URL, Java Mail API | 5 |
| 6 | GUI with JavaFX — Layouts (FlowPane, BorderPane, HBox, VBox, GridPane), UI Controls | 3 |
| 7 | Servlets and Java Server Pages — Lifecycle, Sessions, Cookies, JSP Syntax, Web Frameworks | 8 |
| 8 | RMI and CORBA — Architecture, IDL | 3 |

### Text Books
- Cay S. Horstmann, *Core Java Volume I & II*, Pearson, 11th Ed.
- Herbert Schildt, *Java: The Complete Reference*, McGraw-Hill, 11th Ed.

## 2. Data Warehousing and Data Mining (CSC410)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60+20+20

### Units

| Unit | Title | Hours |
|------|-------|-------|
| 1 | Introduction to Data Warehousing — Multidimensional Model, OLAP, Architecture | 5 |
| 2 | Introduction to Data Mining — KDD, Functionalities, Attribute Types | 2 |
| 3 | Data Preprocessing — Cleaning, Integration, Transformation, Reduction | 3 |
| 4 | Data Cube Technology — Cube Computation, Materialization, Attribute-Oriented Induction | 4 |
| 5 | Mining Frequent Patterns — Apriori, FP-Growth, Association Rules, Lift | 6 |
| 6 | Classification and Prediction — Decision Trees, Naive Bayes, Backpropagation, SVM, k-fold CV | 10 |
| 7 | Cluster Analysis — k-means, k-medoids, Hierarchical, DBSCAN, Outlier Analysis | 8 |
| 8 | Graph Mining and Social Network Analysis — Link Mining, Signed Networks, Trust | 5 |
| 9 | Mining Spatial, Multimedia, Text and Web Data | 2 |

### Text Books
- Jiawei Han et al., *Data Mining: Concepts and Techniques*, 3rd Ed., Morgan Kaufmann
