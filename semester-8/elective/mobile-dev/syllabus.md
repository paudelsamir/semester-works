# Mobile Application Development (CSC470)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60 + 20 + 20
**Pass Marks:** 24 + 8 + 8 | **Semester:** VIII

## Course Description

This course introduces mobile application development frameworks, architectures, design and engineering issues, techniques, methodologies for mobile application development.

## Course Contents

- Mobile Application Development Frameworks
- Mobile Application Architectures
- Design and Engineering Issues
- Techniques and Methodologies for Mobile App Development
- Cross-platform Development
- Mobile App Testing and Deployment
