# Geographical Information System (CSC468)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60 + 20 + 20
**Pass Marks:** 24 + 8 + 8 | **Semester:** VIII

## Course Description

The course covers about spatial data structure, modeling and database design, different techniques for capturing the real world, spatial data manipulation, analysis and visualization, spatial data infrastructure and data standardization, overview of open GIS and open source GIS data.

## Course Contents

- Spatial Data Structure and Modeling
- Database Design for GIS
- Techniques for Capturing Real World Data
- Spatial Data Manipulation
- Spatial Data Analysis and Visualization
- Spatial Data Infrastructure and Data Standardization
- Open GIS Overview
- Open Source GIS Data

## Laboratory Works

Hands-on GIS projects using open source GIS tools.
