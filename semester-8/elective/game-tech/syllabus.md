# Game Technology (CSC465)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60 + 20 + 20
**Pass Marks:** 24 + 8 + 8 | **Semester:** VIII

## Course Description

A practical and conceptual introduction to game design and development including basic ideas of game design, learn to design a game, and working as a game designer. This course will provide ample opportunities to try out concepts and theories to design, develop and test 2D and 3D games. The main platform will be Unity, a cross-platform game editor and engine widely in use by many companies in the game industry.

## Course Contents

- Introduction to Game Design
- Game Design Documents
- Game Mechanics and Dynamics
- 2D Game Development with Unity
- 3D Game Development with Unity
- Game Testing and Quality Assurance
- Game Publishing and Distribution

## Laboratory Works

Hands-on game development projects using Unity engine.
