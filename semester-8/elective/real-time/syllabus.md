# Real Time Systems (CSC471)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60 + 20 + 20
**Pass Marks:** 24 + 8 + 8 | **Semester:** VIII

## Course Description

This course familiarizes students with different concepts of real time systems mainly focusing on scheduling, access control, memory management, optimization, and real time communications.

## Course Contents

- Introduction to Real Time Systems
- Real Time Scheduling
- Access Control
- Memory Management in Real Time Systems
- Optimization Techniques
- Real Time Communications

## Laboratory Works

Implementation of real time system concepts.
