# Distributed and Object-Oriented Database (CSC466)

**Credits:** 3 | **Nature:** Theory + Lab | **Full Marks:** 60 + 20 + 20
**Pass Marks:** 24 + 8 + 8 | **Semester:** VIII

## Course Description

This course aims to discuss concepts of distributed and object oriented database management systems. Main focus is given to basic concepts of DDBMS, distributed database design, distributed query processing, distributed concurrency control, concepts of OODBMS, and language and design of object oriented database.

## Course Contents

### Unit 1. Introduction to Distributed Database Management Systems
### Unit 2. Distributed Database Design
### Unit 3. Distributed Query Processing
### Unit 4. Distributed Concurrency Control
### Unit 5. Object-Oriented Database Management Systems

## Laboratory Works

Implementation of distributed database concepts and object-oriented database design.
