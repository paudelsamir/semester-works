# Lab 26c: React Calculator App

**Student:** Samir Paudel (114-079/D)

## Overview
React Single Page Application with:
- Navbar with navigation
- Footer with copyright
- Home page with profile information
- Calculator functionality (Add, Subtract, Multiply)
- React Hooks (useState) for state management
- React Router for navigation

## Project Setup

```bash
npx create-react-app Lab26c_React_bySamir
cd Lab26c_React_bySamir
npm install react-router-dom
npm start
```

## Components

### Navbar Component
- Navigation links to Home and Calculator
- Active route highlighting with Link

### Home Component
- Profile photo display
- Student information (Name: Samir Paudel, Roll: 114-079/D)

### Calculator Component
- Two input fields with state management
- Operation dropdown
- Compute button
- Result display with conditional rendering

### Footer Component
- Copyright information
- Dynamic year
