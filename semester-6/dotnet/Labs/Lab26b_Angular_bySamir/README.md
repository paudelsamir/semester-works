# Lab 26b: Angular Calculator App

**Student:** Samir Paudel (114-079/D)

## Overview
Angular Single Page Application with:
- Navbar with navigation
- Footer with copyright
- Home page with profile information
- Calculator functionality (Add, Subtract, Multiply)
- Two-way data binding with [(ngModel)]
- Routing between components

## Project Setup

```bash
ng new Lab26b_Angular_bySamir
cd Lab26b_Angular_bySamir
npm install
ng serve --open
```

## Components

### Navbar Component
- Navigation links to Home and Calculator
- Active route highlighting

### Home Component
- Profile photo display
- Student information (Name: Samir Paudel, Roll: 114-079/D)

### Calculator Component
- Two input fields (Number 1 & Number 2)
- Operation dropdown (Add, Subtract, Multiply)
- Compute button
- Result display

### Footer Component
- Copyright information
- Dynamic year display

## Features
✅ Angular Routing  
✅ Two-way Data Binding (ngModel)  
✅ Component Communication  
✅ Event Handling (click)  
✅ Conditional Rendering (*ngIf)
